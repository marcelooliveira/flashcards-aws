# Azure AI Services — Tabela de Referência (2026)

## Microsoft AI Foundry

| Serviço / Feature | Descrição | Casos de Uso |
|---|---|---|
| AI Foundry Portal | Interface web unificada para gerenciar projetos de IA | Criação e monitoramento de projetos de IA corporativos |
| AI Foundry Hub | Governança e colaboração entre times | Gerenciamento centralizado de políticas e segurança |
| AI Foundry SDK | SDK Python + REST API + CLI | Automação de pipelines e integração com DevOps |
| Azure AI Projects | Organização de recursos por projeto com RBAC | Times multidisciplinares desenvolvendo soluções de IA |
| Model Catalog | Catálogo com modelos Microsoft, Open Source e Parceiros | Seleção e implantação de modelos como GPT-4o, Phi-4, Llama 4 |
| Prompt Flow | Orquestração visual de fluxos de LLM | Criação de pipelines RAG, avaliação e teste de prompts |
| Serverless API | Implantação de modelos sem gerenciar infraestrutura | APIs de IA sob demanda com cobrança por token |
| Managed Compute | Compute dedicado para modelos customizados | Fine-tuning e inferência de modelos privados |
