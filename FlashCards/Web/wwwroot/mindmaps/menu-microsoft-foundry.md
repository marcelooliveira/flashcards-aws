| Explore | Model Benchmarks | Comparativo de desempenho entre modelos por métricas de qualidade, velocidade e custo |

| Explore | Capabilities | Visão geral das capacidades disponíveis: visão, linguagem, fala, geração de código |

| Projects | Connected Resources | Gerenciamento de recursos Azure conectados: Storage, Key Vault, AI Search, OpenAI |
| Projects | Settings | Configurações do projeto: nome, descrição, permissões e chaves de API |
